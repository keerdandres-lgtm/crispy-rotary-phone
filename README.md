## Hoidla kasutamine

Käivitus- ja ehituskäske ei ole, sest hoidla ei sisalda rakenduse lähtekoodi. Järgmine samm on määrata hoidla eesmärk või jätta see teadlikult projekti lähtekohaks.

## GitHubis orienteerumine

- **Code**: failid ja viimane kinnitatud versioon.
- **README.md**: projekti sissejuhatus ja käivitusjuhend.
- **Branch**: eraldi tööversioon.
- **Pull request**: muudatuste võrdlus ning kontrollide tulemus.
- **Actions**: automaatsete kontrollide käivitused.
